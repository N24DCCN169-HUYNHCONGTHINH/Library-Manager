# Library Manager

Repository for the existing Windows desktop library manager and the new web MVP.

- **Desktop source:** `library_manager (4).py` (existing application)
- **Web MVP:** see [`web/README.md`](web/README.md)
- **13-day development plan:** [`web/docs/plan-13-ngay.md`](web/docs/plan-13-ngay.md)

The web application is being built separately with Django so its environment and dependencies do not interfere with the desktop app. Do not commit databases, backups, credentials, or real reader data.
