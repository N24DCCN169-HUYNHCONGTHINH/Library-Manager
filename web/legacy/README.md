# Ứng dụng desktop cũ

Mã nguồn và dữ liệu desktop đang ở `D:\QuanLyThuVien_Windows`. Thư mục này chỉ giữ thông tin tham chiếu; không sao chép cơ sở dữ liệu hoặc thông tin độc giả vào repository web.

Khi viết bộ chuyển đổi dữ liệu, dùng bản sao SQLite đã kiểm soát, tạo báo cáo số bản ghi trước/sau và giữ nguyên file nguồn. Chỉ chuyển dữ liệu thật sau khi đã có phê duyệt của người phụ trách và thử khôi phục được.
